# drtools

Reusable DataRobot tool library (`datarobot-genai[drtools]`). Provides agentic tools and credential resolution for MCP servers and in-process agents.

| Doc | Topic |
|---|---|
| [auth.md](auth.md) | Auth resolution strategies and runtime injection (FastMCP, LangChain) |

Install:

```bash
pip install "datarobot-genai[drtools]"
```

For MCP servers, also see `datarobot-genai[drmcpbase]` and `datarobot-genai[drmcp]` in the [repository README](../../../README.md).
